# CEO Business Operating Map

This map routes a fresh session through Riskflow as a business. It is strategy
memory, not runtime authority.

## Operating Route

1. Check runtime authority from generated CEO artifacts.
2. Read `docs/RISKFLOW_AS_BUSINESS.md` and `docs/CEO_STRATEGY_MEMO.md` for
   the first customer, wedge, current strategic bet, and kill criteria.
3. Use [[Customer Discovery Log]], [[Customer Persona - Active Crypto Researcher]],
   and [[Business Assumption Register]] before treating any business claim as
   learned.
4. Use [[Riskflow Customer Value Map]] to translate research into user value.
5. Use [[Product Translation Ladder]] before writing chart-facing language.
6. Use [[Pricing And Packaging]], [[Business Metrics]],
   [[Competitive Positioning]], [[Business Product Roadmap]], and [[GTM
   Experiment Backlog]] to choose the smallest market-facing test.
7. Use `docs/CEO_DELEGATION_MODEL.md`, [[Agent Employee Organization V2]], and
   [[CEO Org Progress Score]] to
   separate real decision movement from specialist activity.
8. Use `docs/CEO_OPERATING_CADENCE.md` for daily/weekly/monthly cadence.
9. Use `docs/CEO_BOARD_REPORTING.md` and [[CEO Board Reports Index]] for
   business-level reporting.

## Runtime Authority

Generated artifacts win over this map. If this map conflicts with `ceo status`,
approval queue, action board, preflight gate, dispatch receipt, eval suite,
guardrail audit, or artifact coherence, reconcile the conflict before acting.
