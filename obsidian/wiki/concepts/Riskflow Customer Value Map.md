# Riskflow Customer Value Map

Riskflow's first value is better chart triage for high-beta crypto researchers.

## User Decisions

- Which chart deserves attention now?
- Which leader is still early enough to matter?
- Which reset is constructive?
- Which move is a late or unsupported warning?
- Which setup should be archived?

## Product Outputs

- scanner prioritization;
- relative leadership context;
- compression and reset read;
- warning/blocker labels;
- visual-review queue;
- archive/do-not-repeat memory.

## Evidence Rule

Every customer-facing statement needs a matching evidence level. If the
evidence is only process, Obsidian, or specialist opinion, use research language
only and keep product claims forbidden.
