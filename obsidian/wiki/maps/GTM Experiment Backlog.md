## Candidate Experiments

### Manual Watchlist Report

- Hypothesis: a serious crypto trader will value a concise relative-leadership
  and warning report.
- Audience: active discretionary crypto trader.
- Manual asset: one weekly watchlist with evidence caveats.
- Ask: would this save time or change what you review?
- Success signal: repeat request or concrete price range.
- Approval required: yes, before sending externally.

### TradingView Companion Demo

- Hypothesis: Riskflow is easier to understand when paired with chart examples.
- Audience: TradingView-native trader.
- Manual asset: annotated screenshots and interpretation guide.
- Ask: does this explain reset, warning, and relative strength better than your
  current indicators?
- Success signal: user can describe when they would use it again.
- Approval required: yes, before sharing externally.

### Scanner Workflow Review

- Hypothesis: ranked local scanner output reduces universe triage time.
- Audience: crypto researcher with a watchlist process.
- Manual asset: CSV/HTML scanner output plus summary.
- Ask: which rows would you open first and why?
- Success signal: user changes their review order or asks for repeat output.
- Approval required: yes, before using external data or user lists.
