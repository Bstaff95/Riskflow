# Riskflow Business Metrics

This document defines business metrics for Riskflow. These metrics are separate
from CEO operating health, lab evidence, and product validation.

Source anchor:

- YC's essential startup advice recommends early companies choose one or two key
  metrics and focus on code plus user conversations:
  https://www.ycombinator.com/blog/ycs-essential-startup-advice

## Metric Categories

### Customer Learning

- interviews completed;
- target-user fit;
- repeated pain count;
- workflow observations;
- exact user-language snippets;
- objections repeated by more than one target user.

### Workflow Value

- charts removed from manual review;
- time saved in triage;
- watchlist decisions made easier;
- avoid/wait decisions clarified;
- reset or warning interpretation improved;
- historical analogs used in a real decision.

### Packaging Signal

- report format requested again;
- TradingView companion requested;
- scanner output reused;
- user asks for a recurring cadence;
- user names a price range;
- user compares Riskflow favorably to a current paid alternative.

### Retention And Pull

- repeat usage across multiple market weeks;
- unsolicited follow-up;
- user sends charts to inspect;
- user changes workflow around Riskflow output;
- user asks for notification, report, or scan cadence.

### Claim Readiness

- evidence-safe product claim exists;
- forbidden claim remains blocked;
- product language has a validation path;
- fresh/withheld or visual-review evidence supports the phrasing;
- risk officer would approve the wording.

## Non-Metrics

These do not count as business traction:

- more internal reports;
- more agent tasks completed;
- more Obsidian notes;
- higher lab process score;
- social excitement without workflow evidence;
- backtest improvement without user-facing value.

## CEO Business Dashboard

A weekly CEO review should report:

- interviews completed: `n`;
- repeated pain themes: `n`;
- workflow observations: `n`;
- WTP signals: `n`;
- retained/repeated users: `n`;
- strongest objection;
- strongest packaging signal;
- product claim that became safer;
- product claim that became less safe;
- next customer-learning action.
